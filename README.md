# Портфолио Даниила Кулакова

Статический сайт без сборки, npm-зависимостей и внешних JavaScript-библиотек. Все изображения, резюме и видео загружаются локально.

## Запуск

В XAMPP включите Apache и откройте `http://localhost/Portfolio/`.

Для просмотра без XAMPP из этой папки:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:4173/`. Остановка сервера — Ctrl+C.

## Редактирование

- Тексты: обновите нужный язык в `translations.js`. Основные английские тексты продублированы в HTML для доступности без JavaScript; при изменениях обновляйте обе версии.
- Проекты: редактируйте `project-data.js`. При добавлении проекта также добавьте карточку в `index.html` и переводы её текста.
- Изображения: обновляйте оригиналы и соответствующие WebP-копии. В увеличенном просмотре используется оригинал; галерея загружает WebP.
- Изображение PC Support: исходник находится в `Screenshots/PC_support/Pc_support.png`; превью — `assets/images/pc-support-1-640.webp` и `pc-support-1-1200.webp`. После замены обновите `imageVersion` проекта и параметр `v` у карточки в HTML, чтобы браузер не показывал старую копию из кеша.
- Логотипы: исходные PNG сохранены в `Logo/`. В шапке используется прозрачный `main-logo-96.webp` с версией 192 px для плотных экранов; готовый логотип с надписью — `main-logo-text-640.webp`. Для вкладки подготовлены `favicon.ico` и `favicon-32.png`, для иконки на домашнем экране — `apple-touch-icon.png`.
- Контакты и PDF: ссылки указаны в HTML; проверьте их в обоих файлах при замене.
- Оформление: базовые цвета, размеры и отступы находятся в `:root` файла `styles.css`.

Язык определяется по настройкам браузера. Ручной выбор сохраняется, если браузер разрешает localStorage. Отказ хранилища не мешает работе сайта. Уровень английского указан как B2, японского — JLPT N2; новые квалификации при переработке не добавлялись.

## Перед публикацией

Размещайте файлы сайта вместе с папками материалов. Сборка и установка пакетов не нужны. Используйте HTTP(S), чтобы корректно работали навигация и функции браузера. Копирование почты требует HTTPS или localhost; обычная почтовая ссылка доступна всегда.

Реальный домен в исходных данных не указан, поэтому вымышленный canonical/og:url удалён. После выбора домена можно добавить абсолютный адрес страницы и изображение для социальных сетей. Подробности проекта загружаются JavaScript; при его отключении показываются ссылка на резюме и возврат к портфолио.
